<Info>
  All paths on this site are relative to **`https://ln-breeze.vercel.app`**. The full URL for this endpoint is `https://ln-breeze.vercel.app/api/v1/wallets`.
</Info>

## Overview

No LNbits account needed. Pass a wallet name and this endpoint creates a wallet on `demo.lnbits.com` by default, returning the credentials you need to call `/api/v1/auth/register`.

If you have your own LNbits instance, pass its URL and the wallet will be created there instead.

This endpoint requires no API key — it is the first step in the onboarding flow.

## Full onboarding flow

```
POST /api/v1/wallets       → { invoiceKey, walletId, lnbitsUrl }
POST /api/v1/auth/register → { apiKey }
       ↓
Use apiKey as Bearer token for all other endpoints
```

## Request body

<ParamField body="walletName" type="string" required>
  A display name for the new wallet. Can be anything — `"My Shop"`, `"Test Wallet"`, `"Personal"`.
</ParamField>

<ParamField body="lnbitsUrl" type="string">
  The LNbits instance to create the wallet on. Defaults to `https://demo.lnbits.com` if not provided. Must be a public HTTPS address — localhost and private IPs are blocked.

  Pass this if you are self-hosting LNbits and want wallets created on your own instance.
</ParamField>

```json
{
  "walletName": "My Shop Wallet"
}
```

To use your own LNbits instance:

```json
{
  "walletName": "My Shop Wallet",
  "lnbitsUrl": "https://lnbits.yourdomain.com"
}
```

## Response

<ResponseField name="walletId" type="string">
  The unique ID of the newly created wallet. Pass this to `/api/v1/auth/register`.
</ResponseField>

<ResponseField name="invoiceKey" type="string">
  The Invoice/Read Key for the wallet. Pass this to `/api/v1/auth/register`.
</ResponseField>

<ResponseField name="walletName" type="string">
  The display name of the wallet as confirmed by LNbits.
</ResponseField>

<ResponseField name="lnbitsUrl" type="string">
  The LNbits instance URL the wallet was created on. Pass this directly to `/api/v1/auth/register`.
</ResponseField>

## Examples

<CodeGroup>

```bash cURL
curl -X POST https://ln-breeze.vercel.app/api/v1/wallets \
  -H "Content-Type: application/json" \
  -d '{ "walletName": "My Shop Wallet" }'
```

```js JavaScript
// Step 1 — Create wallet
const walletRes = await fetch("https://ln-breeze.vercel.app/api/v1/wallets", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ walletName: "My Shop Wallet" }),
});
const { walletId, invoiceKey, lnbitsUrl } = await walletRes.json();

// Step 2 — Register and get API key
const registerRes = await fetch("https://ln-breeze.vercel.app/api/v1/auth/register", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ lnbitsUrl, invoiceKey, walletId }),
});
const { apiKey } = await registerRes.json();
// Store apiKey — you're ready to create invoices
```

```python Python
import requests

# Step 1 — Create wallet
wallet = requests.post(
  "https://ln-breeze.vercel.app/api/v1/wallets",
  json={"walletName": "My Shop"},
).json()

# Step 2 — Register
register = requests.post(
  "https://ln-breeze.vercel.app/api/v1/auth/register",
  json={
    "lnbitsUrl": wallet["lnbitsUrl"],
    "invoiceKey": wallet["invoiceKey"],
    "walletId": wallet["walletId"],
  },
).json()

api_key = register["apiKey"]
```

</CodeGroup>

## Error responses

| Status | Message | What happened |
|---|---|---|
| `400` | `walletName is required` | The `walletName` field is missing |
| `400` | `Invalid LNbits URL` | The `lnbitsUrl` provided is not a valid public HTTPS address |
| `400` | `Failed to create wallet` | LNbits rejected the request — the instance may not support open wallet creation |
| `500` | `Could not reach LNbits` | The LNbits instance was unreachable — try again shortly |
