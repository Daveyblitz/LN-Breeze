<Info>
  All paths on this site are relative to **`https://ln-breeze.vercel.app`**. The full URL for this endpoint is `https://ln-breeze.vercel.app/api/v1/auth/register`.
</Info>

## Overview

This is the only endpoint that does not require an API key. You call it once per wallet to receive your Bearer token. From that point on, every other API call uses that token — your raw LNbits credentials never need to travel over the network again.

LN-Breeze verifies your credentials against LNbits before issuing a key. If the credentials are invalid, or if the LNbits instance is unreachable, no key is issued.

## Request body

<ParamField body="lnbitsUrl" type="string" required>
  The base URL of your LNbits instance. Must be a public HTTPS address.

  Accepted: `https://demo.lnbits.com`

  Rejected: `http://...`, `localhost`, private IP ranges (`10.x`, `192.168.x`, `172.16–31.x`), cloud metadata endpoints
</ParamField>

<ParamField body="invoiceKey" type="string" required>
  Your LNbits Invoice/Read Key. This is the read-only key that allows creating and checking invoices. Found in your wallet under **API Info → Invoice/Read Key**.

  This is intentionally not the Admin Key — LN-Breeze only ever needs read and invoice permissions.
</ParamField>

<ParamField body="walletId" type="string" required>
  Your LNbits Wallet ID. Found in your wallet under **API Info → Wallet ID**.
</ParamField>

## Response

<ResponseField name="apiKey" type="string">
  A signed JWT containing your sealed LNbits credentials. Use this as the Bearer token in all subsequent requests.

  Store it immediately — it is not saved by LN-Breeze and cannot be retrieved later. If you lose it, call this endpoint again to get a new one.
</ResponseField>

<ResponseField name="walletName" type="string">
  The display name of your LNbits wallet, as returned by LNbits on verification. Useful for confirming you connected the right wallet.
</ResponseField>

<ResponseField name="note" type="string">
  A reminder that the key will not be shown again.
</ResponseField>

## Request body

```json
{
  "lnbitsUrl": "https://demo.lnbits.com",
  "invoiceKey": "YOUR_INVOICE_KEY",
  "walletId": "YOUR_WALLET_ID"
}
```

<Tip>
  Don't have an LNbits wallet yet? Call `POST /api/v1/wallets` first — it creates one and returns the `invoiceKey`, `walletId`, and `lnbitsUrl` ready to paste here.
</Tip>

## Examples

<CodeGroup>

```bash cURL
curl -X POST https://ln-breeze.vercel.app/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "lnbitsUrl": "https://demo.lnbits.com",
    "invoiceKey": "a1b2c3d4e5f6a1b2c3d4e5f6a1b2c3d4",
    "walletId": "f6e5d4c3b2a1f6e5d4c3b2a1f6e5d4c3"
  }'
```

```js JavaScript
const res = await fetch("https://ln-breeze.vercel.app/api/v1/auth/register", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    lnbitsUrl: "https://demo.lnbits.com",
    invoiceKey: process.env.LNBITS_INVOICE_KEY,
    walletId: process.env.LNBITS_WALLET_ID,
  }),
});

const { apiKey, walletName } = await res.json();
// Store apiKey in your environment — do not log it
console.log(`Connected to: ${walletName}`);
```

```python Python
import requests, os

res = requests.post(
  "https://ln-breeze.vercel.app/api/v1/auth/register",
  json={
    "lnbitsUrl": "https://demo.lnbits.com",
    "invoiceKey": os.environ["LNBITS_INVOICE_KEY"],
    "walletId": os.environ["LNBITS_WALLET_ID"],
  }
)

data = res.json()
api_key = data["apiKey"]
# Write api_key to your secrets manager or .env file
```

</CodeGroup>

## Error responses

| Status | Message | What happened |
|---|---|---|
| `400` | `lnbitsUrl, invoiceKey, and walletId are required` | One or more fields are missing from the request body |
| `400` | `Invalid LNbits URL` | The URL is not a public HTTPS address — localhost, private IPs, and HTTP are blocked |
| `401` | `Invalid credentials or could not reach LNbits` | LNbits rejected the credentials, or the instance was unreachable |
| `500` | `Registration failed` | Unexpected server error — try again |
